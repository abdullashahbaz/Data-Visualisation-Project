# Olympics Data Story


##  Overview & Theme
A One page interaction based data story which explores the relations between national wealth (GDP) and Olympic Success

Adresses if wealthier countries acheive greater dominance in the olympics, while highlighting the outliers and the long term historical paths trajectories formed


##  Technologies Used
- HTML
- CSS
- JavaScript
- D3.js v7


##  Main Project Structure
- `index.html` - main page structure
- `styles/main.css` - page styling and theme
- `scripts/main.js` - data loading, chart rendering, interactions
- `docs/` - contains the project documentation files

##  How to Run it
1. Open the project folder in VS Code
2. start Live Server
3. open the local browser link
4. make sure the original dataset files are placed inside `data/` folder


##  Visualizations

## 1. Bubble Chart
displays a bubble chart with country gdp vs the medals won by that country

## 2. Medal Efficiency Map
Choloropleth map based on relative gdp and medal efficiency

## 3. Olympic Journey Through Time
shows the development of a selected country over the year range
